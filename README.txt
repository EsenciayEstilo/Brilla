BRILLA VELAS Y AÑO VIEJO — INSTRUCCIONES DE CARGA

IMPORTANTE: todos los archivos de este paquete están al mismo nivel. No hay que cargar una carpeta de imágenes.

1. Descomprime Brilla_Catalogo_Archivos_Individuales.zip.
2. En tu repositorio actual de GitHub, abre la carpeta raíz (la misma donde está el index.html que publica GitHub Pages).
3. Carga/reemplaza index.html y carga también cada una de las imágenes individualmente, todas en esa misma carpeta raíz.
4. No crees una carpeta llamada "imagenes" y no cambies los nombres de las fotografías. El index.html busca las imágenes por sus nombres exactos.
5. Incluye README.txt si deseas conservar estas instrucciones en el repositorio.
6. Confirma los cambios (Commit changes) y espera a que GitHub Pages publique la actualización.

Archivos principales:
- index.html
- Las fotografías originales (cada una por separado)
- README.txt

Antes de compartir el enlace con clientes, abre la página publicada y prueba cantidades (+ y -), subtotal, nombres y teléfono obligatorios, selección de cajas y adhesivos, y el mensaje de WhatsApp.

Nota: esta carga conserva el enlace siempre que reemplaces los archivos en el mismo repositorio y en la misma ubicación de publicación.
