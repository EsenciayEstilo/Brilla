BRILLA VELAS Y AÑO VIEJO 2026

PAQUETE LIMPIO SIN ARCHIVOS DUPLICADOS
Este ZIP contiene el index.html, este README y las fotografías para el catálogo actualizado. Todos los archivos están en la raíz para facilitar la carga manual en GitHub.

ACTUALIZAR EL REPOSITORIO EXISTENTE
1. Descomprime este ZIP en tu computador.
2. En el repositorio BrillaMagic, usa Add file > Upload files.
3. Carga index.html y README.txt para reemplazar los existentes.
4. Carga las imágenes que no existan ya en la raíz del repositorio. Si GitHub pregunta por reemplazar un archivo con el mismo nombre, usa la versión de este paquete.
5. Confirma los cambios. No crees otro repositorio ni elimines el enlace público.

REFERENCIAS
Velas blancas, pastel y neón; portavelas de madera; Año Viejo 2026 con selección separada Hombre y Mujer y la imagen del contenido como referencia; cinco diseños de cajas y ocho diseños de adhesivos.

Los precios conservados en el catálogo deben confirmarse si el proveedor los cambió. No se inventaron cantidades de inventario por diseño.
