BRILLA VELAS Y AÑO VIEJO — INSTRUCCIONES PARA CARGAR EN GITHUB

IMPORTANTE: En GitHub, los archivos se cargan MANUALMENTE Y DE FORMA INDIVIDUAL. No subas el ZIP ni crees una carpeta llamada “imagenes”.

ARCHIVOS QUE DEBES CARGAR
1. Reemplaza el archivo index.html existente por el index.html de esta entrega.
2. Selecciona y carga cada fotografía como archivo individual, una por una o seleccionando varios archivos a la vez. Todas deben quedar en la misma ubicación raíz que index.html.
3. Conserva exactamente el nombre de cada fotografía, incluidos espacios, tildes y extensiones.
4. No cambies los nombres de los archivos ni los pongas dentro de una carpeta adicional.
5. Guarda/commitea los cambios en el mismo repositorio para conservar el enlace de la página.
6. README.txt es solo una guía; puedes cargarlo individualmente si deseas conservar las instrucciones en el repositorio.

NOTA SOBRE EL ARCHIVO ZIP
El ZIP solo sirve para transportar todos los archivos juntos. En tu computador, accede a los archivos que contiene y luego súbelos manualmente a GitHub siguiendo las instrucciones anteriores. En GitHub, la carga final debe quedar como archivos individuales, no como un ZIP ni como una carpeta de imágenes.
