BRILLA VELAS Y AÑO VIEJO — INSTRUCCIONES DE CARGA

IMPORTANTE: Este ZIP NO se carga directamente en GitHub.

1. Descomprime el ZIP en tu celular o computador.
2. Abre la carpeta extraída.
3. Entra a tu repositorio de GitHub actual.
4. Carga index.html y reemplaza el index.html existente.
5. Selecciona y carga individualmente todas las fotografías en la MISMA ubicación donde está index.html. No las pongas dentro de una carpeta llamada imágenes.
6. Conserva exactamente los nombres originales de las fotografías. El catálogo busca los archivos por esos nombres.
7. Puedes cargar también este README.txt individualmente para conservar las instrucciones.
8. Confirma/guarda los cambios en GitHub. No crees otro repositorio.

ORDEN DEL CATÁLOGO
1) Elegir color y cantidad de paquetes de velas.
2) Elegir caja (gratis).
3) Elegir adhesivo (gratis).
4) Indicar si desea portavelas; si responde sí, aparece el selector de cantidad.
5) Elegir kits de Año Viejo para hombre o mujer y cantidades.
6) Completar nombre y teléfono obligatorios.
7) Añadir observaciones opcionales y confirmar por WhatsApp.

Precios configurados: velas $18.000 por paquete de 10; portavelas $15.000 por unidad; kit Año Viejo $20.000 por kit. La selección de caja y adhesivo no tiene costo adicional.
