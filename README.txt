BRILLA VELAS Y AÑO VIEJO 2026

ARCHIVOS DEL SITIO
- index.html: catálogo interactivo con selección de productos, resumen y envío por WhatsApp.
- README.txt: instrucciones para mantener y actualizar el sitio.
- Imágenes PNG/JPG: fotografías originales suministradas para las referencias disponibles.

CARGA MANUAL EN GITHUB
Las fotografías se cargan individualmente en la raíz del repositorio, al mismo nivel que index.html. Este sitio utiliza rutas directas a los nombres de archivo y no requiere una carpeta assets/ ni activos/.

PARA ACTUALIZAR SIN VOLVER A SUBIR LAS FOTOS
1. Abre el repositorio BrillaMagic en GitHub y entra en Code.
2. Selecciona Add file > Upload files.
3. Arrastra únicamente index.html y README.txt para reemplazar las versiones existentes.
4. Confirma con Commit changes.
5. Verifica Settings > Pages: rama main y carpeta /(root).
6. Abre el sitio publicado y prueba imágenes, cantidades, subtotal y mensaje de WhatsApp.
